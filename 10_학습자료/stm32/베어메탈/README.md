# STM32 베어메탈 시리즈

HAL·OS 등 추상화 계층 없이 **레지스터 레벨에서 직접 STM32를 제어**하는 학습 노트 모음.

- **타겟 MCU:** STM32F407 (Streamline F407 보드)
- **원본 강의:** STM32 Bare Metal Tutorial (YouTube)

## 학습 흐름

1. **부팅 메커니즘** — 링커 스크립트, 벡터 테이블, Reset 핸들러
2. **GPIO 직접 제어** — RCC 클럭 활성화, MODER, BSRR
3. _이후 회차 추가 시 갱신_

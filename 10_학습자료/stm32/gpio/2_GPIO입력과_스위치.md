# STM32 입문 #4 — GPIO 입력과 스위치

**주제:** GPIO를 입력 모드로 설정해 외부 스위치 신호를 읽고, 그 상태에 따라 LED를 켜고 끄기
**타겟 MCU:** STM32F767VIT6
**원본 강의:** [(210) STM32 입문 강의 몰아보기 | ARM, GPIO, ADC, UART (YouTube)](https://www.youtube.com/watch?v=XOsyrZGZtR8)

> **실습 목표:** PD4에 연결된 스위치 입력에 따라 PD3의 Fault LED를 켜고 끈다.

---

## 1. GPIO 입력 — 전압 한계와 내부 회로

GPIO 포트는 출력뿐 아니라 입력으로도 쓸 수 있다. 외부 신호를 받을 때 **최대 3.3V까지** 받아들인다.

GPIO 내부 블록도의 **Input Driver** 쪽 구성:
- **Protection Diode** — 과전압 보호 (출력 편과 동일). 입력 신호가 VDD+0.7V를 넘거나 VSS−0.7V 아래로 내려가면 다이오드가 켜져 과전압을 흘려보낸다.
- **Pull-up / Pull-down 저항** — 내부 저항을 선택해 쓸 수 있다.
- **Schmitt Trigger** — 입력단에 내장돼 **노이즈에 강인**하게 신호를 판별. (자세한 동작은 인버터 설계 시 홀센서 입력에서 다룸.)

들어온 신호는 **Input Data Register(IDR)** 로 읽는다. 3.3V가 들어오면 해당 비트가 `1`, 0V면 `0`.

> **예외 — 5V 입력 가능한 핀(FT).**
> F767은 원칙적으로 입력 최대 3.3V지만, 데이터시트의 IO Structure에 `FT`로 표시된 핀(예: PA4·PA5·PA6)은 **5V 신호 입력이 가능**하다. 단 **ADC로 쓸 때는 3.3V만** 가능하다. 추후 홀센서 5V 신호를 받을 때 이 FT 핀을 활용한다.

> **이미지 필요**
> GPIO 내부 블록도 — Input Driver(Protection Diode, Pull-up/down, Schmitt Trigger, IDR) 경로 강조
> - 출처: STM32F767 레퍼런스 매뉴얼 GPIO 챕터, 강의 57:30~58:30
> - 대체안: 레퍼런스 매뉴얼 "Basic structure of an I/O port bit" 그림

## 2. 실습 회로 — 풀업 스위치

- **LED:** GPIO 출력 편과 동일한 PD3의 Fault LED.
- **스위치:** PD4에 연결. R4가 **풀업 저항**, C6은 캐퍼시터.

동작:
- **스위치 OPEN(안 누름)** → 풀업으로 입력에 **3.3V** → IDR 비트 = `1`
- **스위치 SHORT(누름)** → 입력이 GND로 떨어져 **0V** → IDR 비트 = `0`

즉 PD4의 IDR 비트를 읽어 스위치 상태를 판단한다.

| 스위치 | 입력 전압 | IDR(PD4) |
| --- | --- | --- |
| OPEN | 3.3V | 1 |
| 눌림 | 0V | 0 |

---

## 3. 레지스터 설정

### 3.1 클럭 활성화 (RCC)

출력 편과 동일하게, 포트 D만 쓰므로 GPIOD 클럭만 enable한다.

```c
RCC->AHB1ENR |= (1 << 3);   // GPIOD 클럭 enable
```

### 3.2 모드 설정 (MODER)

- **PD3 → 출력 모드(`01`)**: LED용.
- **PD4 → 입력 모드(`00`)**: 스위치용.

```c
// PD3 출력: bit 6,7 = 01
GPIOD->MODER &= ~(0b11 << 6);
GPIOD->MODER |=  (0b01 << 6);

// PD4 입력: bit 8,9 = 00
GPIOD->MODER &= ~(0b11 << 8);
```

> **주의 — 입력 모드는 0이라 안 해도 되지만, 명시적으로 클리어한다.**
> 입력 모드(`00`)는 초기값과 같아 굳이 설정 안 해도 된다. 그래도 8·9번 비트를 명시적으로 클리어하는 이유는 ① **가독성**, ② **혹시 모를 오류 대비**로 확실하게 입력 모드를 보장하기 위해서다. (강의 코드엔 PD4 풀업 활성화 줄도 있으나 이 실습에선 사용 안 함.)

> **클리어 후 세팅 패턴:** 출력 편에서도 강조했듯, 먼저 `&= ~(...)`로 해당 비트를 0으로 클리어한 뒤 `|= (...)`로 원하는 값을 세팅하면 실수 없이 정확히 설정되고 가독성도 좋다.

## 4. 입력 읽기 — IDR과 AND 마스킹

`while(1)` 안에서 PD4의 IDR 비트를 계속 확인한다. **AND 연산으로 특정 비트만 마스킹**해서 읽는다.

```c
while (1) {
    if ((GPIOD->IDR & (1 << 4)) == 0) {
        // 스위치 눌림(0V) → LED ON
        GPIOD->ODR &= ~(1 << 3);
    } else {
        // 스위치 뗌(3.3V) → LED OFF
        GPIOD->ODR |= (1 << 3);
    }
}
```

해석:
- `GPIOD->IDR & (1 << 4)` → IDR의 4번 비트만 추출.
- 결과가 `0` → PD4가 Low(0V) → **스위치 눌림** → LED ON.
- 결과가 `1`(0이 아님) → PD4가 High(3.3V) → **스위치 뗌** → LED OFF.

> **참고 — IDR은 읽기 전용(r).**
> 레지스터 맵에서 IDR 비트는 `r`(read only)로 표시된다. 읽을 수만 있다는 뜻이다. 반면 MODER 같은 레지스터는 `rw`(read/write)라 읽기·쓰기 모두 된다. 레지스터 맵의 이 표기를 참고하면 좋다.

## 면접 답변 (30초 분량)

> `/easy-quiz` 실행 시 이 섹션이 정답 카드로 사용됩니다.

- **한 줄 정의:** GPIO 입력은 MODER를 입력 모드(00)로 설정하고 IDR 레지스터에서 핀의 High/Low를 읽는 것이다.
- **왜 필요:** 스위치·센서 같은 외부 디지털 신호를 MCU가 받아들이려면 입력 모드 설정과 상태 읽기가 필요하다.
- **동작:** RCC로 포트 클럭을 켜고 MODER를 00으로 둔다. 입력단에는 Protection Diode·Pull-up/down·Schmitt Trigger가 있어 과전압 보호와 노이즈 내성을 준다. 풀업 스위치는 안 누르면 3.3V(IDR=1), 누르면 0V(IDR=0)다. IDR을 AND 마스킹해 특정 핀 비트만 읽는다.
- **비교:** 출력은 ODR에 쓰고(rw), 입력은 IDR에서 읽기만 한다(read only). F767 입력은 최대 3.3V지만 FT 핀은 5V까지 견딘다(ADC 용도 제외).
- **30초 통합 답변:**
  > GPIO 입력을 쓰려면 RCC로 포트 클럭을 켠 뒤 MODER를 00으로 둬서 입력 모드로 만듭니다. 입력 모드는 초기값이라 사실 안 건드려도 되지만 가독성과 안전을 위해 명시적으로 클리어합니다. 입력단에는 과전압을 막는 Protection Diode, 내부 Pull-up/down, 그리고 노이즈에 강하게 만드는 Schmitt Trigger가 있습니다. 제 실습 회로는 풀업 스위치라 안 누르면 3.3V로 IDR이 1, 누르면 0V로 0이 됩니다. while 루프에서 IDR을 1<<4로 AND 마스킹해 PD4 비트만 읽고, 0이면 스위치가 눌린 것으로 보고 LED를 켰습니다. IDR은 읽기 전용 레지스터고 F767 입력은 최대 3.3V지만 FT로 표시된 핀은 5V까지 받을 수 있습니다.

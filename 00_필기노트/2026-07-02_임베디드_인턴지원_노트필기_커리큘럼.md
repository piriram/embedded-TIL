# 임베디드 인턴 지원용 노트필기 커리큘럼

작성일: 2026-07-02

## 목표

이 커리큘럼의 목표는 임베디드 전체 정복이 아니다.

목표는 아래 수준이다.

> 노트필기한 내용은 면접에서 30초-1분 답변으로 말할 수 있다.  
> 이 상태가 되면 임베디드 인턴/신입 포지션에 지원을 시작한다.

타겟 예시:

- 임베디드 SW 인턴
- 펌웨어 인턴
- MCU 펌웨어 신입
- 임베디드 테스트/검증 인턴
- C 기반 장비 SW 인턴

## 전체 순서

```text
1. 주변장치 3종: GPIO / UART / Interrupt
2. 임베디드 기초
3. MCU 기본 동작
4. C언어 심화
5. Timer / PWM
6. 통신 3종: I2C / SPI / CAN
7. 디버깅 / 검증
8. 미니 프로젝트 설명 준비
9. 면접 답변화
10. 지원 시작
```

## 완주 기준

각 장은 A4 세로 반 접기 2열 노트 기준으로 작성한다.

- 1페이지 = 2열
- 1열 = 32줄 기준
- 들여쓰기 없음
- 색상: 파랑 구조, 검정 설명, 빨강 주의/면접 포인트
- 32줄은 배치 기준이다. 한 주제를 한 페이지에 억지로 넣지 않고, 길면 다음 페이지로 넘긴다.
- 필수 개념은 충분히 쓰고, 참고 개념은 짧게 붙인다.

한 장을 끝냈다는 기준:

1. 제목만 보고 내용을 설명할 수 있다.
2. 빨간색 포인트만 보고 면접 주의점을 말할 수 있다.
3. Q에 적은 질문에 최소 1개 답할 수 있다.

## 1단계: 임베디드 기초

목표:

> 임베디드가 일반 앱/웹 개발과 뭐가 다른지 설명한다.

필기 주제:

1. 임베디드 시스템이란
2. MCU / CPU / SoC 차이
3. 펌웨어란
4. 센서, 액추에이터, 통신의 관계
5. Bare-metal / RTOS / Embedded Linux 차이
6. 데이터시트와 레퍼런스 매뉴얼의 역할

면접 답변 목표:

> 임베디드는 특정 하드웨어와 목적에 맞춰 동작하는 소프트웨어이며, MCU의 핀, 레지스터, 주변장치를 제어해 센서 입력이나 장치 출력을 다룹니다.

필기 분량:

- 3페이지

목표:

> 대학교에서 배운 C를 임베디드 관점으로 다시 연결한다.

필기 주제:

1. 포인터와 주소
2. 배열과 포인터 차이
3. 포인터 연산
4. `const`
5. `static`
6. `volatile`
7. 구조체와 패딩
8. 비트필드
9. 비트연산: set / clear / toggle / check
10. 매크로와 `inline`
11. 함수 포인터
12. 메모리 영역: stack / heap / data / bss / flash

면접 답변 목표:

> 임베디드 C에서는 하드웨어 레지스터를 주소로 접근하기 때문에 포인터, 비트연산, volatile 이해가 중요합니다.

필기 분량:

- 6페이지

## 3단계: MCU 기본 동작

목표:

> MCU가 레지스터와 클럭을 통해 주변장치를 제어한다는 감각을 만든다.

필기 주제:

1. Memory-mapped I/O
2. 레지스터란
3. 레지스터 직접 제어 vs HAL
4. 클럭과 클럭 트리
5. GPIO 주변장치 클럭 enable
6. startup code와 vector table 개념
7. Flash / SRAM / Peripheral memory map

면접 답변 목표:

> Memory-mapped I/O는 주변장치 레지스터가 CPU 주소 공간에 배치되어 메모리처럼 읽고 쓸 수 있게 하는 구조입니다.

필기 분량:

- 4페이지

## 4단계: GPIO / UART / Interrupt

목표:

> 임베디드 입구 3종 세트를 말과 코드 흐름으로 이해한다.

필기 주제:

1. GPIO Output: LED 제어
2. GPIO Input: 버튼 읽기
3. Pull-up / Pull-down
4. Push-pull / Open-drain
5. UART 기본: TX / RX / GND
6. Baud rate와 `115200 8N1`
7. UART 로그 출력과 디버깅
8. Polling vs Interrupt
9. ISR이란
10. ISR에서 하면 안 되는 것
11. Debouncing
12. EXTI 버튼 인터럽트

면접 답변 목표:

> GPIO는 핀을 입력/출력으로 사용해 외부 회로와 디지털 신호를 주고받는 기본 인터페이스이고, UART는 TX/RX로 로그나 데이터를 주고받는 비동기 직렬 통신입니다. 인터럽트는 이벤트 발생 시 CPU가 ISR을 실행하는 방식입니다.

필기 분량:

- 6페이지

## 추천 순서

현재 상태에서는 아래 순서가 가장 안전하다.

```text
1. GPIO / UART / Interrupt
2. 임베디드 기초
3. MCU 기본 동작
4. C언어 심화
5. Timer / PWM
6. I2C
7. SPI
8. CAN
9. 디버깅 / 검증
10. 면접 답변화
```

이유:

- 지금 막히는 지점이 임베디드 입구 3종 세트이기 때문이다.
- C는 이미 대학교에서 배웠으므로 처음부터 다시 깊게 파기보다, GPIO/UART/Interrupt와 MCU 구조를 본 뒤 임베디드식으로 재정리하는 편이 낫다.
- 포인터, volatile, 비트연산은 GPIO/UART/Interrupt와 레지스터 개념을 본 뒤 공부해야 필요성이 더 선명해진다.
- I2C/CAN은 GPIO/UART/Interrupt 감각이 생긴 뒤 들어가야 덜 무섭다.
- 디버깅/검증은 이미 가진 TTA 경험과 연결하면 강점이 된다.

# 주제별 강의노트 기반 면접·지원 커리큘럼

작성일: 2026-07-15

## 목적

이 문서는 `필기노트`만 먼저 외우다가 개념 연결이 끊기는 문제를 해결하기 위한 학습 순서다.

필기노트는 처음 배우는 원문이 아니라 **이해한 내용을 면접에서 30~60초로 말하기 위한 압축 답변 카드**로 사용한다.

```text
주제별 강의노트로 원리 이해
→ 필기노트로 면접 핵심 압축
→ 화면 없이 30초 설명
→ 지원과 면접 피드백으로 보강
```

목표는 임베디드 전체를 완주하는 것이 아니다.

> GPIO, UART, Interrupt, C 핵심, I2C 기초와 검증 경험을 사실대로 설명하며 지원을 시작한다.

## 학습 원칙

### 하루 90분 루틴

| 시간 | 할 일 | 산출물 |
|---|---|---|
| 50분 | 주제별 강의노트를 예시·그림·코드 흐름 중심으로 읽는다. | 원리를 설명하는 문장 1개 |
| 20분 | 해당 필기노트에서 면접에 말할 문장만 확인한다. | 핵심 키워드 3개 |
| 10분 | 화면을 닫고 30초 답변을 녹음한다. | 음성 또는 말하기 연습 |
| 10분 | `왜 필요한가 / 어떻게 동작하는가 / 실패하면 무엇을 확인하는가`를 한 줄씩 쓴다. | 막힌 질문 1개 |

- 주제별 노트를 읽어도 이해가 끊기는 지점만 원본 YouTube 영상에서 찾아 본다. 처음부터 영상 전체를 완주하지 않는다.
- 레지스터 이름·비트 번호를 암기하는 대신, 데이터와 제어 흐름을 이해한다.
- 모르는 내용은 건너뛰지 말고 `막힌 질문`으로 남긴다. 그 질문은 다음 면접 대비 항목이다.

### 1주차 종료 시 지원 기준

아래를 모두 30~60초로 말할 수 있으면, 완벽하지 않아도 사실 기반으로 지원한다.

- GPIO, UART, Interrupt의 역할과 기본 실패 원인
- 포인터와 배열의 차이
- `volatile`의 역할과 한계
- 비트 mask의 set / clear / check
- I2C의 주소, pull-up, ACK/NACK, `WHO_AM_I` 검증 흐름
- 30초 자기소개와 TTA 검증 경험의 임베디드 연결
- 모르는 질문에 대한 대응: `인정 → 연결 경험 → 확인 방법 → 학습 계획`

지원 범위와 최소 기준은 [지원 시작](./필기노트_10_지원_시작.md)을 따른다. 지원은 학습 종료 선언이 아니라, 어떤 질문에서 막히는지 확인하는 피드백 루프다.

## 우선순위 조절

### 지금 반드시 할 것

- C: 포인터·배열, `volatile`, bit mask
- MCU: MMIO, GPIO, UART, Interrupt
- 통신: I2C의 기본 흐름과 실패 확인
- 검증: 재현 조건, 기대 결과, 실제 결과, 회귀 확인
- 자기소개와 모르는 질문 대응

### 지원과 병행해 할 것

- Timer / PWM
- SPI / CAN 개념 비교
- RTOS task / scheduler / mutex / semaphore
- 프로젝트 아키텍처와 검증 증거 설명

### 지금 깊게 파지 않을 것

- AUTOSAR 세부 계층과 설정 도구
- bootloader 업데이트 시퀀스
- CAN 진단·UDS·오류 상태의 상세 구현
- 고급 RTOS 동기화와 멀티코어
- ADC·DMA의 상세 레지스터 설정

이 영역은 공고의 필수요건이거나 면접 피드백에서 반복될 때만 확장한다.

## MCU 모델 차이 주의

주제별 STM32 강의노트는 주로 **STM32F767** 기준이고, 포트폴리오는 **STM32F103** 기준이다.

따라서 주제별 노트에서는 아래 원리만 가져온다.

- GPIO를 쓰기 전 해당 주변장치 clock을 켠다.
- 레지스터는 메모리 주소처럼 읽고 쓴다.
- 입력에는 floating을 막는 pull-up/down이 필요할 수 있다.
- 인터럽트에서는 긴 작업을 하지 않고, 빠르게 상태를 기록한 뒤 main/task로 넘긴다.

`MODER`, `AHB1ENR`처럼 F767에 맞는 정확한 레지스터 이름·비트 위치는 F103에 그대로 적용하거나 암기하지 않는다. F103 구현은 프로젝트 문서와 해당 데이터시트를 기준으로 확인한다.

## 매일 남길 3줄 템플릿

```text
주제:
왜 필요한가:
어떻게 동작하는가:
실패하면 무엇부터 확인하는가:
30초 답변에서 막힌 문장:
```

막힌 문장이 하나 남는 것은 실패가 아니다. 다음 날 원본 강의나 면접 답변 카드로 보강할 정확한 목표가 생긴 것이다.

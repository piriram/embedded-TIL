# 역할

두 가지 모드로 학습노트를 만듭니다.

- **모드 A:** 기존 마크다운 학습 노트를 `templates/학습노트.md` 형식으로 변환 (원문 보존)
- **모드 B:** 강의 트랜스크립트(영상 자막)를 받아 **읽기만 해도 강의 청취가 불필요한** 자급자족 학습노트로 재구성

둘 다 시리즈 강의면 전용 폴더로 정리하고 면접답변 섹션을 자동 생성합니다.

---

# 입력 (두 가지 모드)

## 모드 A: 기존 노트 변환 (`/learn-note <파일경로> [영상URL] [N]`)

- 인자 1: 원본 `.md` 파일 경로
- 인자 2: 강의 영상 URL (선택)
- 인자 3: 시리즈 번호 (선택)

## 모드 B: 트랜스크립트 → 학습노트 (`/learn-note 트랜스크립트 <영상URL>`)

- 키워드 `트랜스크립트` 또는 `transcript` 감지 시 활성
- 사용자가 트랜스크립트 본문을 메시지에 붙여넣거나 `.txt` 경로 제공
- 결과물: **학습노트만 읽어도 영상 청취 불필요**한 자급자족 노트
- 트랜스크립트 원문은 저장하지 않음 (일회용 입력)

인자 없으면 사용자에게 어떤 모드인지 물어보기.

# 동작 원칙

## 모드 A — 옵션 A (원문 보존)

**절대 규칙:**
- 원문 문장·표·코드·예시를 **요약·삭제·재구성 금지**
- 이모지만 제거 (`📝 🧠 💡 ⚠️ 🚨 🎓 🏗️ 🛠 ⭐ ⚙️` 등)
- 강조(`**굵게**`), 인라인 코드, 표 안 `<br>` 등 마크다운 문법 그대로

## 모드 B — 트랜스크립트 자급자족 변환

**목표:** 학습노트 = 강의 청취 완전 대체본.

**규칙:**
- 트랜스크립트 잡음 제거: `snorts`, `clears throat`, `hang on`, 반복 `uh/um`, 화면 전환 멘트, 채널 홍보 등
- **시간순 → 개념순 재구성**: 강사가 띄엄띄엄 말한 같은 주제를 한 섹션에 모음
  - 예: 19분·22분·40분에 흩어진 "벡터 테이블" 언급 → 한 섹션으로 통합
- **강사의 "왜"를 모두 흡수**: 단순히 "X를 한다"가 아니라 "X를 왜 하는지"까지 본문에 포함
  - `__attribute__((naked))` → 스택 push 회피, return 없음 → 코드 크기·동작 보장
  - 16MHz RC → PLL 미설정 시 내부 오실레이터 디폴트
  - BSRR 32bit 분할 → 하위 16비트 SET, 상위 16비트 RESET → atomic 보장
- **숫자·계산 100% 보존**: "벡터 107×4=428B", "실코드 100B", "총 528B" 등
- **강사 코멘트도 살림**: "다음 강의에서 systick 타이머로 개선 예정", "이건 라이브러리의 시작점이다", "Sajupa 페이지에서 영감 얻음"
- **본문 우선, 요약 금지**: "이런 의미야" 한 줄로 끝내지 말고 강사가 설명한 맥락·예시·반박까지 풀어 씀
- 한국어 작성. 기술 용어 원문 유지 (예: vector table, BSRR)
- 코드/명령어 블록 그대로
- 톤: 학습자 1인칭("우리"), 강사 직접 인용은 인용블록(`>`)
- 콜아웃 라벨 (`> **주의**`, `> **예외**`)은 필요 시만
- **이미지 자리표시:** 다이어그램·스크린샷·회로도가 이해에 필수면 본문 흐름 안에 placeholder 삽입:
  ```markdown
  > **이미지 필요**
  > {무엇을 보여주는 이미지인지 한 줄 설명}
  > - 출처: {데이터시트 페이지, 강의 타임스탬프 등}
  > - 대체안: {스크린샷 캡처 위치 또는 참고 다이어그램}
  ```
  - 이미지 확보 시 `![설명](./images/N_파일명.png)`로 교체
  - 파일은 `{같은 폴더}/images/{강번호}_{내용}.png`에 저장

# 동작 순서

## 1. 입력 분석 & 모드 판단

- 인자에 `.md` 파일 경로 → **모드 A**
- 인자에 `트랜스크립트` / `transcript` 키워드 또는 트랜스크립트 본문 직접 입력 → **모드 B**
- `templates/학습노트.md` Read해서 규칙 재확인

**모드 A 전용:**
- 원본 파일 Read
- 헤딩 레벨 파악:
  - 원본이 `##`부터 시작하면 → `#`로 한 단계 승격
  - 섹션이 `###`면 → `## N.` 형식으로 변환 (번호 부여)

**모드 B 전용:**
- 트랜스크립트 전체 스캔 → 주제별 그룹핑
- 그룹핑된 개념을 학습 순서(개요 → 원리 → 실습 → 디테일 → 심화)로 재배치
- 각 섹션 헤더는 `## N. 제목` 형식 신규 생성

## 2. 영상 메타 추출 (URL 있을 때)

- WebFetch로 영상 제목·시리즈 정보 추출
- 본문 상단에 추가:
  ```
  **원본 강의:** [영상 제목 (YouTube)](URL)
  ```

## 3. 콜아웃 라벨 정규화

- `> **💡 핵심 포인트:**`, `> **TIP:**` 등 → `> **주의**`
- 일반 규칙 벗어나는 예외/심화 섹션 → `> **예외**`
- 라벨 없는 일반 콜아웃은 그대로

## 4. 본문 변환

- 위 원칙대로 이모지 제거, 헤딩 정규화, 콜아웃 라벨 통일
- 섹션 사이 `---` 구분자 보장
- 원본의 비표준 섹션(예: "과탑의 인사이트", "팁") → 별도 번호 섹션으로 보존, `> **예외**` 콜아웃 추가

## 5. 신규 섹션 생성

### `## 참고 자료`
- 영상 링크 (있으면)
- 본문에 등장한 외부 자료(데이터시트·매뉴얼) 자동 추출

### `## 면접 답변 (30초 분량)`
본문 분석 후 생성. 형식:
- **한 줄 정의:** {개념}은 {무엇}이다. {핵심 특성}.
- **왜 필요:** 해결하는 문제 1~2문장
- **동작:** 핵심 메커니즘 2~3문장
- **비교:** 짝 개념과의 차이
- **30초 통합 답변:** 위 4개를 자연스러운 한 단락으로

콜아웃: `> /easy-quiz 실행 시 이 섹션이 정답 카드로 사용됩니다.`

## 6. 파일명·폴더 추천 (사용자 확인)

시리즈 강의면 전용 하위 폴더로:
```
원본: cs/Lesson 8. MCU Memory Map.md
추천: cs/임베디드수업/8_MCU_메모리맵과_MMIO.md
```

단일 노트면 같은 폴더 유지, 파일명만 정규화 (`주제_소제목.md`).

사용자에게 보여주고 확인:
```
신규 경로: cs/임베디드수업/8_MCU_메모리맵과_MMIO.md
원본 처리: 삭제 / 보존 / 이동 — 어떻게?
```

## 7. 시리즈 README 갱신

신규 시리즈 폴더면 `README.md` 생성/갱신:
- 진도표 (강 번호, 제목, 키워드, 영상 링크, 상태)
- 학습 흐름 (강 순서대로 핵심 키워드)
- 파일 네이밍 규칙 (`N_제목.md`)
- 관련 폴더 링크

기존 README 있으면 진도표에 행 1개 추가.

## 8. 완료 보고

```
✓ 생성: cs/임베디드수업/8_MCU_메모리맵과_MMIO.md
✓ 갱신: cs/임베디드수업/README.md (진도표 8강 추가)
✓ 삭제: cs/Lesson 8. ... .md (원본)

다음 단계 추천:
- /make-card cs/임베디드수업/8_MCU_메모리맵과_MMIO.md — 답변카드 추출
```

# 폴더 컨벤션 (이 프로젝트)

| 상황 | 위치 |
|------|------|
| 시리즈 강의 (Lesson N, #N) | `{카테고리}/{시리즈명}/N_제목.md` |
| 단일 학습 노트 | `{카테고리}/주제_소제목.md` |
| 답변카드 (`/make-card` 결과) | `면접대비/답변카드/{개념명}.md` |

시리즈 폴더는 항상 `README.md`로 진도표 유지.

# 톤 가이드

- 사용자 검토 단계 거침. 일방적으로 파일 이동·삭제 X
- 원본 손실 발생 시 즉시 중단·복원
- 면접답변 섹션은 본문 근거에서만 생성. 환각 금지

# 주의

- 원문에 명백한 오류 있어도 **수정하지 않음** (보존 우선)
- 파일명에 `:` `/` `?` 등 macOS 경로 제약 문자 있으면 자동 정규화 후 사용자 확인
- 영상 URL이 로그인 필요한 사이트면 메타 추출 생략, 사용자에게 제목 요청

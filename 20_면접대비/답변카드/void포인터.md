# void 포인터

> 파생 학습노트: `10_주제별/c언어/포인터.md`
> 최종 갱신: 2026-05-18

---

## 30초 통합 답변

> 면접 직전 이것만 소리내어 읽는다. 입에 붙을 때까지.

void 포인터는 가리키는 데이터의 타입이 아직 정해지지 않은 범용 포인터입니다. 타입을 모르기 때문에 주소부터 몇 바이트를 읽을지, 비트를 어떻게 해석할지 알 수 없어서 직접 역참조하거나 포인터 연산을 할 수 없습니다. 쓰려면 반드시 원하는 타입으로 캐스팅한 뒤 사용해야 합니다. 대표적인 예가 malloc인데, malloc은 메모리만 덩그러니 할당해 주므로 반환값이 void*입니다.

---

## 한 줄 정의

void 포인터는 가리키는 대상의 타입이 정해지지 않은 범용 포인터다. 캐스팅해야 쓸 수 있다.

## 왜 필요한가

타입에 상관없이 어떤 주소든 담을 수 있는 일반 포인터가 필요할 때 쓴다. malloc처럼 어떤 타입으로 쓰일지 모르는 함수의 반환 타입에 적합하다.

## 동작 원리

타입 정보가 없어 읽을 바이트 수와 해석 방식을 알 수 없다. 따라서 역참조(`*ptr`)와 포인터 연산(`ptr++`)이 불가능하다. 사용 전에 `(int *)` 같은 캐스팅으로 타입을 부여해야 한다.

## 비교 / 대안

- **vs 일반 포인터:** 일반 포인터는 타입이 있어 바로 역참조·연산 가능, void*는 캐스팅 전까지 불가.

---

## 꼬리질문 예상

- **Q:** void 포인터를 바로 역참조하면?
  **A:** 컴파일 에러. 타입을 몰라 몇 바이트를 어떻게 읽을지 결정할 수 없다.

- **Q:** void 포인터는 어디서 보나요?
  **A:** malloc/calloc의 반환 타입. 메모리만 할당하고 타입은 사용자가 캐스팅으로 정한다.

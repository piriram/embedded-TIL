## 작성 규칙

- 대제목은 `# 주제명` 형식으로 작성한다.
- 주요 섹션은 `## 1. 제목` 형식으로 번호를 붙인다.
- 하위 개념은 필요할 때만 `### 제목`을 사용한다.
- 기본 콜아웃은 라벨 없이 사용한다.
- 실수하기 쉬운 내용과 예외만 `> **주의**`, `> **예외**` 라벨을 사용한다.
- 목록은 기본적으로 `-`를 사용한다.
- 순서가 중요한 내용만 `1.` 형식의 번호 목록을 사용한다.
- 용어의 첫 정의, 핵심 수식·코드 표현, 반드시 기억할 결론만 `**볼드**`로 강조한다. 한 문장 전체를 반복해서 굵게 처리하지 않는다.
- 섹션 사이는 `---`로 구분한다.
- 마지막에는 `## 참고 자료` 섹션을 둔다.

## 이미지 자리표시 규칙

- 다이어그램·스크린샷·회로도 등 시각 자료가 이해에 필수면 해당 위치에 placeholder를 둔다.
- 형식 (콜아웃 박스):

  ```markdown
  > **이미지 필요**
  > {무엇을 보여주는 이미지인지 한 줄 설명}
  > - 출처: {데이터시트 페이지, 강의 타임스탬프, 또는 직접 작성 등}
  > - 대체안: {스크린샷 캡처 위치 또는 참고할 다이어그램}
  ```

- 본문 흐름 안에 그대로 둬서 렌더링 시에도 눈에 띄게 한다 (놓치지 않게).
- 이미지 확보 시 `![설명](./images/N_파일명.png)` 형식으로 교체.
  - 이미지 파일은 같은 폴더의 `images/` 하위에 저장 (예: `10_주제별/stm32/베어메탈/images/1_vector_table.png`).
  - 파일명: `{강번호}_{내용}.png` 형식.

## 기존 노트에 템플릿 적용 시 규칙 (옵션 A: 원문 보존)

- **원문 100% 보존이 기본.** 문장·표·코드·예시를 임의로 요약하거나 삭제하지 않는다.
- 이모지는 모두 제거한다 (예: `🧠`, `⚠️`, `📝`, `🎓` 등).
- 템플릿 골격(섹션 번호, `---` 구분자, `## 참고 자료`, `## 면접 답변`)만 새로 적용한다.
- 원본에 없는 `## 참고 자료`, `## 면접 답변` 섹션은 신규로 추가한다.
- 원본의 `**굵게**`, 인라인 코드 등 강조 표시는 유지한다.
- 표 안의 `<br>` 등 원본 마크다운 문법은 그대로 둔다.
- 원본의 "팁/인사이트" 같은 비표준 섹션은 별도 번호 섹션으로 살리되 `> **예외**` 라벨로 감싼다.
- 신규 파일로 저장하고 원본은 삭제하지 않는다.

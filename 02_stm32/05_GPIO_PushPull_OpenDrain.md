# GPIO 제어 방식: Push-Pull과 Open-Drain

GPIO(General Purpose Input/Output) 핀을 출력으로 사용할 때, 신호를 구동하는 방식은 크게 두 가지로 나뉩니다.

## 1. Push-Pull (푸시풀)
트랜지스터 두 개가 짝을 이루어 동작하며, 핀을 강제로 High(VDD) 또는 Low(GND) 상태로 밀어주거나 당겨주는 가장 일반적인 출력 방식입니다.
- **원리**:
  - `1`을 출력하면 상단 스위치(P-MOS)가 켜져 전류를 밀어냅니다(Push).
  - `0`을 출력하면 하단 스위치(N-MOS)가 켜져 전류를 흡수합니다(Pull).
- **특징**: 신호 전환이 빠르고, LED 점등이나 단순 제어에 가장 적합합니다.
- **주의점**: 두 장치가 동일한 선에 연결되어 서로 다른 상태(한쪽은 High, 한쪽은 Low)를 밀어내면 합선(Short)이 발생해 칩이 타버릴 수 있습니다.

## 2. Open-Drain (오픈 드레인)
내부에 하단 스위치(N-MOS)만 존재하여 핀을 Low(GND)로만 당길 수 있는 방식입니다. High 신호는 스스로 만들지 않고 외부 회로에 맡깁니다.
- **원리**:
  - `0`을 출력하면 스위치가 켜져 선이 Low(GND)가 됩니다.
  - `1`을 출력하면 스위치가 꺼지면서 핀이 공중부양 상태(High-Z, 플로팅)가 됩니다.
  - 따라서 선이 High가 되려면 외부에 **풀업 저항(Pull-up Resistor)**을 연결해야 합니다.
- **특징**: 여러 기기가 하나의 선을 공유하는 통신(예: I2C)에 필수적입니다. 누군가 선을 Low로 당기면(통신 중) 전체 선이 Low가 되고, 아무도 당기지 않으면 풀업 저항에 의해 High가 됩니다. 충돌이 발생해도 합선되지 않습니다.

## 3. AF (Alternate Function)
GPIO 핀을 단순 켜기/끄기(Output/Input)가 아니라 MCU 내부의 특수 통신 하드웨어(I2C, UART, SPI 등)에 연결하여 사용할 때 지정하는 모드입니다.

## 4. 실전 예시 (오늘의 학습)
- **LED 제어 (PC13)**: 강제로 전류를 당기거나 밀어서 제어해야 하므로 일반 **Push-Pull** 모드로 설정했습니다.
- **MPU6050 통신 (PB6, PB7)**: I2C 통신을 수행해야 하므로 핀의 제어권을 통신 블록에 넘기는 **AF 모드**로 설정하고, 버스 충돌 방지를 위해 **Open-Drain** 방식으로 정확히 구성했습니다.

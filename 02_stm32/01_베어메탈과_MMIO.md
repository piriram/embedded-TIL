# 베어메탈(Bare-metal)과 MMIO (Memory-Mapped I/O)

## 1. 베어메탈(Bare-metal) 제어란?
운영체제(OS)나 제조사가 제공하는 고수준 라이브러리(예: STM32 HAL, Arduino Core) 없이 하드웨어를 밑바닥부터 직접 제어하는 방식을 말합니다.
- **장점**: 시스템 리소스(메모리, 실행 시간)를 극도로 최적화할 수 있으며, 하드웨어의 동작 원리를 정확히 이해할 수 있습니다.
- **단점**: 개발 난이도가 높고 디버깅이 까다롭습니다.

## 2. MMIO (Memory-Mapped I/O)란?
임베디드 시스템에서 CPU가 주변장치(Peripheral)와 통신하는 핵심 방식입니다.
- MCU 내부의 다양한 장치들(GPIO, I2C, SPI 등)을 제어하기 위한 **레지스터(Register)**들이 특정한 **'메모리 주소'**에 할당되어 있습니다.
- 따라서 C 언어의 포인터를 이용해 특정 메모리 주소에 값을 쓰거나 읽는 것만으로 하드웨어를 직접 제어할 수 있습니다.

### 실전 예시 (오늘의 학습)
`main.c` 파일에서 어떠한 라이브러리 없이 다음과 같이 작성했습니다.
- 특정 메모리 주소(예: `0x40021000` 등)를 구조체나 포인터로 매핑합니다.
- 이 주소에 직접 `1`과 `0`의 비트(Bit) 값을 조작하여 LED를 켜거나 I2C 모듈을 설정했습니다.
- 이는 하드웨어 레지스터 맵을 정확히 이해하고 데이터 시트를 기반으로 코드를 작성했다는 것을 의미합니다.

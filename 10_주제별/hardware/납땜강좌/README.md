## 학습 흐름

1. **최소 도구 구성** — Soldering Iron, Solder Wire, Universal PCB를 중심으로 실습을 준비한다.
2. **기판 선택** — 단면과 양면 Universal PCB의 작업 면과 활용도 차이를 구분한다.
3. **보조제와 정비 도구** — Flux와 Tip Cleaner의 역할을 헷갈리지 않도록 정리한다.
4. **반복 연습** — 저가형 장비로 작은 Solder Joint부터 반복해 숙달한다.
5. **열전달 문제 진단** — Solder가 안 녹을 때 합금, Tip, Thermal Mass, Flux, 보조 가열 순으로 점검한다.

## 파일 네이밍 규칙

- `N_제목.md` 형식을 사용한다.
- `N`은 원본 강의의 편 번호다.
- 번호가 없는 특별 강의는 `특별편_제목.md` 형식을 사용한다.
- 핵심 전문 용어는 `Soldering Iron`, `Flux`, `Solder Joint` 처럼 표준 English 표기를 유지한다.

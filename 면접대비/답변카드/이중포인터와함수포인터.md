## 30초 통합 답변

> 면접 직전 이것만 소리내어 읽는다. 입에 붙을 때까지.

포인터 변수도 결국 Stack에 공간을 차지하는 변수라, 그 주소를 가리키는 또 다른 포인터를 만들 수 있습니다. 이게 이중 포인터고, main 함수의 argv가 대표적입니다 — 문자열들의 배열을 가리키는 포인터죠. 함수 포인터는 함수가 Code 영역에 저장된 명령어 집합이고 함수 이름이 그 시작 주소를 의미한다는 점을 이용한 겁니다. 함수 자체를 다른 함수의 인자로 넘길 수 있어 콜백 구현에 씁니다. 선언할 때 int (*ptr)(int, int)처럼 괄호를 꼭 쳐야 하는데, 괄호가 없으면 포인터를 반환하는 함수로 해석됩니다.

---

## 한 줄 정의

이중 포인터는 포인터 변수의 주소를 가리키는 포인터다. 함수 포인터는 함수의 시작 주소를 가리키는 포인터다.

## 왜 필요한가

이중 포인터: 함수 안에서 포인터 변수 원본 자체를 바꾸거나 포인터 배열을 다룰 때 필요하다. 함수 포인터: 실행할 함수를 인자나 변수로 넘겨 콜백·동적 디스패치를 구현하기 위해 필요하다.

## 동작 원리

포인터 변수도 Stack에 저장되는 변수이므로 그 주소를 또 다른 포인터에 담을 수 있다(이중 포인터). 함수는 Code 영역의 명령어 집합이고 함수 이름은 그 시작 주소이므로, 그 주소를 포인터에 담아 호출할 수 있다(함수 포인터).

## 비교 / 대안

- **단일 vs 이중 포인터:** 단일은 일반 변수의 주소, 이중은 포인터 변수의 주소를 가리킨다.
- **함수 포인터 선언:** `int (*ptr)(int,int)`는 함수 포인터, `int *ptr(int,int)`는 포인터 반환 함수.

## 꼬리질문 예상

- **Q:** 이중 포인터는 어디서 쓰나요?
  **A:** main의 argv(문자열 배열을 가리키는 포인터), 함수 안에서 포인터 원본 자체를 바꿀 때.

- **Q:** 함수 포인터 선언에 괄호가 왜 필요한가요?
  **A:** `int (*ptr)(int,int)`처럼 괄호를 쳐야 함수 포인터로 인식된다. 없으면 int 포인터를 반환하는 함수로 해석된다.

- **Q:** 함수 포인터는 어디에 쓰나요?
  **A:** 콜백 함수 구현. 함수 자체를 다른 함수의 인자로 넘길 때.

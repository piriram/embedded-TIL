# 오답노트

`/easy-quiz` 실행 중 사용자가 모호하게 답하거나 못 떠올린 정확한 용어를 자동으로 축적합니다.
다시 마주칠수록 빈도가 올라가고, 자연스럽게 입에 붙습니다. 외우려 하지 않아도 됩니다.

---

## 자주 놓치는 정확 표현

| 모호한 표현 | 정확한 용어 | 출처 파일 | 빈도 |
|------------|-----------|----------|------|
| "최적화하지 말라고 시키기" | "객체의 읽기·쓰기를 실제 메모리 접근으로 유지하도록 강제" | 면접대비/답변카드/volatile_키워드.md | 1 |
| "캐싱 안 하고 매번 읽음" (읽기만 언급) | "읽기·쓰기 모두 실제 메모리 접근으로 유지" | 면접대비/답변카드/volatile_키워드.md | 1 |
| "const는 값이 변하지 않도록 강제" | "const는 내 코드가 이 값을 수정하지 않겠다는 약속 (외부 변경은 별개)" | 면접대비/답변카드/volatile_키워드.md | 1 |
| "volatile이 long에만 붙어있다" | "벤더 헤더 매크로에 volatile이 붙어있다 (long이라서가 아님)" | 면접대비/답변카드/unsigned_int_vs_unsigned_long.md | 1 |
| (막힘) 32비트 폭 보장 타입 못 떠올림 | "정확한 폭이 필요하면 stdint.h의 uint32_t" | 면접대비/답변카드/unsigned_int_vs_unsigned_long.md | 1 |

## 사용 방법

- `/easy-quiz` 시 자동 갱신됨
- 직접 수정 가능
- 빈도 3 이상 = 다음 퀴즈에서 우선 출제
- `/easy-quiz 오답` 으로 이 노트 기반 미니 퀴즈

---

## 작성 규칙

- 사용자 답을 그대로 기록 (창피주기 X, 패턴 인식 O)
- 정확한 용어는 학습 노트 본문에서 추출
- 같은 모호 표현 중복 시 빈도 +1, 새 행 추가 X

# 함수형 전처리기 매크로

**원본 강의:** [How to Write Function-Like Preprocessor Macros — Jacob Sorber (YouTube)](https://www.youtube.com/watch?v=w3iXBUbq4NY)

## 1. 매크로는 함수가 아니라 텍스트 치환

```c
#define BAD_SQR(x) x * x
#define SQR(x)     ((x) * (x))

BAD_SQR(1 + 2)  // 1 + 2 * 1 + 2 -> 5
SQR(1 + 2)      // ((1 + 2) * (1 + 2)) -> 9
```

안전한 표현식 매크로는 **각 인수**와 **전체 치환식**을 괄호로 감싼다. 매크로 이름과 `(` 사이에는 공백을 넣지 않는다.

---

## 2. 괄호가 해결 못 하는 부작용

```c
int i = 3;
int v = SQR(i++);  // ((i++) * (i++)): i++가 두 번 평가
```

매크로 본문에 인수가 두 번 나오면 `i++`, 함수 호출, `volatile` read 같은 인수도 두 번 평가된다. 위 예시는 같은 객체를 sequencing 없이 여러 번 수정하므로 undefined behavior다. 타입 검사도 없다.

여러 문장 매크로는 다음처럼 한 문장으로 묶는다.

```c
#define LOG(x) do { log_value(x); ++log_count; } while (0)
```

> **주의**
> 일반 연산에는 `static inline`이 타입 검사·scope·한 번 평가를 주므로 더 안전하다.

## 면접 답변 (30초 분량)

- **한 줄 정의:** 함수형 매크로는 전처리기가 인수를 포함해 치환하는 텍스트 규칙이다.
- **왜 필요:** 조건부 컴파일, bit mask, 파일·줄 번호 캡처처럼 전처리기만 할 수 있는 일을 한다.
- **동작:** 인수와 전체 식에 괄호를 쓰고, 여러 문장은 `do { } while (0)`으로 묶는다.
- **비교:** 매크로는 타입 검사가 없고 인수를 여러 번 평가하지만 `static inline` 함수는 그렇지 않다.
- **30초 통합 답변:**
  > 함수형 매크로는 함수 호출이 아니라 컴파일 전 텍스트 치환입니다. `#define SQR(x) ((x) * (x))`처럼 인수와 전체 식을 괄호로 감싸 우선순위 문제를 막아야 합니다. 하지만 `SQR(i++)`는 인수를 두 번 평가하므로 괄호로도 안전하지 않습니다. 타입 검사와 한 번 평가가 필요한 작은 연산은 `static inline`을 우선하고 매크로는 전처리기 고유 역할에 제한합니다.

# STM32 입문 #5 — 클럭과 PLL 설정

**주제:** MCU 클럭의 종류(HSE/HSI/LSE/LSI), 프리스케일러, PLL로 216MHz 만들기, 오버드라이브, 그리고 앞으로 계속 쓸 `init_MCU` 함수 분석
**타겟 MCU:** STM32F767VIT6
**원본 강의:** [(210) STM32 입문 강의 몰아보기 | ARM, GPIO, ADC, UART (YouTube)](https://www.youtube.com/watch?v=XOsyrZGZtR8)

> **목표:** 외부 16MHz 크리스탈(HSE)을 PLL에 넣어 **216MHz 시스템 클럭**을 만들고, APB1·APB2를 54MHz로 설정한다.

---

## 1. 왜 클럭이 핵심인가

MCU 내부의 모든 동작은 **클럭에 동기화**되어 실행된다. 클럭 주파수가 높으면 명령어 처리를 더 빠르게 한다. F767은 최대 **216MHz**까지 동작하는데, 이 속도를 내려면 뒤에 나오는 **PLL**과 **오버드라이브** 설정이 필요하다.

클럭은 AHB1 버스(216MHz)로 분배되고, 브릿지를 통해 APB1(최대 54MHz)·APB2(최대 108MHz)로 나뉜다.

---

## 2. 프리스케일러 — 주파수 분주

**프리스케일러(Prescaler)** 는 클럭 주파수를 나눠(분주) 낮추는 장치다. GPIO·ADC·타이머 등 모듈마다 존재한다.

예: 입력 100MHz에 분주비 ÷2 → 출력 50MHz.

왜 일부러 낮추나?
1. **전력 절감** — 주파수가 높으면 전력 소비가 늘어난다. 빠를 필요 없는 모듈을 굳이 빠르게 돌릴 이유가 없다.
2. **원하는 주기 만들기** — 타이머/카운터에서 세는 간격을 조정하려면 적절한 주파수가 필요하다.

---

## 3. 네 가지 클럭 소스 — HSE / HSI / LSE / LSI

| 클럭 | 풀네임 | 주파수 | 특징 |
| --- | --- | --- | --- |
| **HSE** | High Speed External | 외부 크리스탈(4~26MHz) | 외부 크리스탈/세라믹 레조네이터/외부 클럭. 이 보드는 **16MHz 크리스탈** + 캐퍼시터 2개 사용. 정밀. |
| **HSI** | High Speed Internal | **16MHz 고정** | 내부 RC 오실레이터. 외부 소자 불필요(원가↓)지만 **정밀도 낮음**. **리셋 직후 디폴트 시스템 클럭.** |
| **LSE** | Low Speed External | 32.768kHz | 외부 핀. 저전력으로 RTC에 공급. (이 강의는 미사용) |
| **LSI** | Low Speed Internal | 약 32kHz | 내부 RC. 정지/대기 모드, 워치독·RTC 공급. |

> **주의 — 리셋 직후엔 HSI.**
> 전원이 켜지는 순간 디폴트로 **HSI(16MHz)** 가 시스템 클럭이 된다. 외부 오실레이터가 실패·정지해도 내부 HSI로 버틴다. 우리는 더 빠른 클럭을 원하므로 HSI로 일단 시작한 뒤 안정화되면 PLL로 전환한다.

---

## 4. PLL — 주파수 체배 회로

**PLL(Phase-Locked Loop)** 은 입력 클럭(HSI 또는 HSE)을 받아 **더 높은 출력 주파수**를 만드는 체배 회로다. 내부에 **VCO**라는 회로가 있는데, **VCO는 1~2MHz 입력에서 안정적**이라고 데이터시트에 명시돼 있다.

이 강의의 216MHz 계산:
1. HSE 16MHz를 **÷8** → 2MHz (VCO 안정 구간으로 맞춤)
2. **×216** → 432MHz
3. **÷2** → **216MHz** (시스템 클럭)

> PLL48 클럭은 USB 등 기타 주변 장치용이라 이 강의에선 미사용.

PLL 설정 순서(레지스터):
1. **PLL ON 비트 = 0** (PLL 잠시 끔)
2. **READY 비트가 0** 되길 대기
3. **`RCC_PLLCFGR`** 에서 분주비(÷8, ×216, ÷2 등) 설정
4. **PLL ON 비트 = 1** (동작 시작)
5. **READY 비트가 1** 될 때까지 대기

> **이미지 필요**
> 클럭 트리 — HSI/HSE → PLL → System Clock → AHB Prescaler(HCLK) → APB1/APB2 Prescaler(PCLK1/PCLK2)
> - 출처: STM32CubeIDE Clock Configuration 화면 / RCC 클럭 트리, 강의 1:15~1:19
> - 대체안: CubeIDE의 Clock Configuration 탭 캡처

---

## 5. 클럭 설정 순서 (제조사 권장)

리셋 후 정해진 순서를 따라야 한다.

1. 리셋 직후 `RCC_CFGR` 디폴트로 **HSI가 시스템 클럭**, 프리스케일러 1 → CPU는 16MHz HCLK로 동작.
2. **HSE·HSI 둘 다 ON** (`RCC_CR`의 해당 비트 = 1).
3. **HSI READY 대기** — `while`로 `RCC_CR`의 HSI READY 비트가 1 될 때까지 폴링.
4. 시스템 클럭을 HSI로 임시 설정(`RCC_CFGR`을 0으로 — 초기값이라 명시적 표현).
5. PLL 분주비 설정 후 PLL ON, PLL READY 대기.
6. **오버드라이브** 처리(아래 6장) → 216MHz 사용 가능.
7. `RCC_CFGR`에서 시스템 클럭을 **PLL 출력**으로 전환, APB1·APB2를 **54MHz**로 설정.

READY 대기 `while` 패턴 (계속 응용됨):

```c
RCC->CR |= (1 << 0);                  // HSI ON
while (!(RCC->CR & (1 << 1)));        // HSI READY(bit1)=1 까지 대기
```

> 동작 원리: READY 비트가 0이면 AND 결과가 0 → `!0`=1 → 루프 계속. READY가 1이 되면 AND 결과가 1 → `!1`=0 → 루프 탈출. **HSI가 준비될 때까지 기다리는 것.**

---

## 6. 오버드라이브 — 216MHz의 조건

> **주의**
> 오버드라이브(Over-drive)를 안 켜면 **최대 180MHz**까지만 가능하다. 216MHz를 쓰려면 반드시 켜야 한다.

오버드라이브는 MCU 내부 **전압 레귤레이터(LDO)** 의 출력 전압을 높이는 기능이다. 소비 전류는 늘지만 최고 속도를 낼 수 있다.

순서:
1. `RCC_APB1ENR`에서 **내부 전압 모듈(PWR) 클럭 enable** (레귤레이터도 클럭으로 동작).
2. `PWR_CR1`에서 **오버드라이브 enable 비트** = 1.
3. 오버드라이브 **READY** 확인.
4. 오버드라이브로 **스위칭**(전환) 완료 → CPU 클럭 216MHz 완성.

---

## 7. 타이머 클럭 216MHz — 숨겨진 함정

> **주의 — 데이터시트에 작게 숨겨진 조건.**
> APB2는 데이터시트상 최대 108MHz로 적혀 있지만, **타이머 클럭은 216MHz까지** 끌어올릴 수 있다. 단, `RCC_DCKCFGR1` 레지스터의 **TIMPRE(타이머 프리스케일러 선택, 24번 비트)** 를 1로 설정해야 한다. 이걸 놓치면 타이머 클럭 설정에서 고생한다.

또한 **APB 프리스케일러가 1이면** PCLK가 그대로 타이머에 가지만, **1이 아니면 PCLK의 2배**가 타이머에 공급된다는 점도 기억할 것.

추가로 **CSS(Clock Security System)** 를 enable(`RCC_CR` 19번 비트=1)하면 내부적으로 클럭 안정도를 감지한다. 고속(50MHz 이상) 동작 시에는 **I/O 보상(Compensation Cell)** 을 enable해 온도·전압 변화로 인한 신호 품질 저하를 자동 보상한다.

---

## 8. init_MCU 함수 — 앞으로 계속 재사용

강사가 제공하는 `init_MCU` 함수가 위 전 과정을 담고 있다. **이후 모든 실습에서 복붙해 클럭 초기화에 사용**한다. 구성:

1. **I-Cache / D-Cache enable** — `core_cm7.h`(CMSIS)의 인라인 함수 사용. 빠른 코어(216MHz)와 느린 Flash의 속도 차를 캐시로 메움.
2. **Flash 설정 — Wait State.**
   - 216MHz에서 1사이클 = **4.6ns**. Flash 접근은 약 **35ns**.
   - 35 ÷ 4.6 ≈ 7.6 → **7 wait cycle** 대기. 데이터시트도 216MHz·해당 전압 레인지에서 7 wait state를 권장.
3. **클럭 설정** — HSE/HSI ON → HSI 안정화 대기 → HSI 임시 시스템 클럭 → PLL 분주비(÷8 ×216 ÷2) → PLL ON·READY 대기 → 오버드라이브 → 시스템 클럭 PLL 전환 → APB1/APB2 = 54MHz.
4. **I/O 보상 셀 enable.**

```c
// 사용 예
init_MCU();   // 이후 실습마다 맨 앞에서 호출
```

## 면접 답변 (30초 분량)

> `/easy-quiz` 실행 시 이 섹션이 정답 카드로 사용됩니다.

- **한 줄 정의:** PLL은 HSE/HSI 입력을 체배해 고주파 시스템 클럭을 만드는 회로이고, F767은 PLL+오버드라이브로 216MHz를 낸다.
- **왜 필요:** 리셋 직후 디폴트는 HSI 16MHz라 느리다. 빠른 처리를 위해 외부 크리스탈을 PLL로 체배해 216MHz를 만든다.
- **동작:** HSE 16MHz ÷8=2MHz(VCO 안정 구간) ×216=432MHz ÷2=216MHz. HSI로 부팅→안정화 대기→PLL 분주비 설정→PLL ON·READY 대기→오버드라이브로 LDO 전압을 올려야 216MHz 가능→시스템 클럭을 PLL로 전환, APB1/APB2 54MHz.
- **비교:** HSE는 외부 크리스탈로 정밀, HSI는 내부 16MHz로 부정밀하지만 외부 소자 불필요. LSE/LSI는 RTC·워치독용 저속·저전력. 프리스케일러는 분주로 전력 절감·주기 조정.
- **30초 통합 답변:**
  > STM32는 리셋 직후 내부 HSI 16MHz로 부팅합니다. 더 빠른 216MHz를 쓰려면 외부 16MHz 크리스탈인 HSE를 PLL에 넣습니다. PLL 내부 VCO가 1~2MHz에서 안정적이라 16MHz를 8로 나눠 2MHz로 만든 뒤 216을 곱해 432MHz, 다시 2로 나눠 216MHz를 얻습니다. 순서는 HSE·HSI를 켜고 HSI로 임시 동작시키며 안정화를 폴링으로 기다린 뒤, PLL 분주비를 설정하고 PLL을 켜서 READY를 기다립니다. 216MHz는 오버드라이브를 켜야만 가능한데, 내부 전압 레귤레이터 출력을 높이는 기능입니다. 마지막으로 시스템 클럭을 PLL로 전환하고 APB1·APB2를 54MHz로 설정합니다. 이 전 과정을 init_MCU 함수로 만들어 캐시·Flash wait state 설정과 함께 이후 모든 실습에서 재사용합니다.

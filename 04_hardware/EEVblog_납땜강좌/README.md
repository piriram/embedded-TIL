## 학습 흐름

1. **도구 선택** — Station, Solder Wire, Tip, 보조 도구를 작업 목적에 맞게 고른다.
2. **열과 재료 이해** — 열용량, Tip 접촉 면적, Solder Alloy와 Flux의 역할을 연결한다.
3. **Through-hole 실습** — Pad와 Lead를 함께 가열해 정상적인 Solder Joint를 만든다.
4. **SMD 실습** — Tweezers, 확대 장비, Flux와 Drag Soldering을 활용한다.
5. **검사와 Rework** — Joint를 확대 검사하고 Wick, Solder Sucker, Hot Air로 수정한다.
